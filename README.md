## 🌟 Tentang Proyek
**SyntaxTrust Vibe Lab SMK** adalah aplikasi web inovatif yang dirancang khusus untuk membantu siswa dan guru SMK (Sekolah Menengah Kejuruan) dalam mempelajari konsep Jaringan Komputer (Networking) dan *Internet of Things* (IoT). 

Aplikasi ini menggabungkan kekuatan **AI Multimodal (Gemini 1.5 Flash)** dengan alat praktikum interaktif untuk menciptakan pengalaman belajar yang modern, futuristik, dan mudah dipahami.

## ✨ Fitur Unggulan

### 1. 🖥️ Networking Toolset
*   **Subnetting Calculator**: Menghitung Network Address, Netmask, Broadcast, dan Usable Host secara instan.
*   **Visual Bit Mapping**: Visualisasi biner (Network vs Host bits) untuk mempermudah pemahaman CIDR.
*   **Command Cheat Sheet**: Referensi cepat perintah Cisco IOS, MikroTik, dan Linux Server.

### 2. 🤖 IoT Firmware Engine
*   **Auto-Code Generator**: Membuat kode program Arduino/ESP32 untuk berbagai sensor (DHT22, Ultrasonik, MQ2 Gas, LCD I2C) secara otomatis.
*   **Wiring Connection Guide**: Panduan pemasangan kabel fisik berdasarkan kode yang dihasilkan, sangat membantu siswa saat merakit alat.

### 3. 🧠 AI Lab Mate (Gemini 1.5 Flash)
*   **Multimodal Vision**: Siswa dapat mengunggah foto alat lab atau rangkaian kabel, dan AI akan menganalisis serta memberikan petunjuk perbaikan.
*   **Voice-Enabled Assistance**: Interaksi suara (Text-to-Speech) dalam Bahasa Indonesia untuk membantu siswa yang lebih suka belajar lewat pendengaran.
*   **Typewriter Interaction**: Respon AI yang interaktif dan nyaman dibaca.

### 4. 📄 Professional Lab Report
*   **PDF Export**: Seluruh hasil perhitungan jaringan, kode IoT, dan riwayat konsultasi AI dapat diunduh langsung menjadi file laporan PDF resmi.

---

## 🛠️ Teknologi yang Digunakan
*   **Core**: HTML5, Vanilla JavaScript.
*   **Styling**: Tailwind CSS (Modern, Dark Mode, Glassmorphism).
*   **AI Engine**: Google AI Studio - Gemini 1.5 Flash API.
*   **Animations**: CSS Keyframes & SVG Animation (Zero Dependency).
*   **PDF Engine**: jsPDF Library.

## 🚀 Cara Menjalankan
1.  Clone repositori ini atau download source code.
2.  Pastikan Anda memiliki server lokal (seperti XAMPP atau Live Server VS Code).
3.  Simpan file logo Anda sebagai `logo.png` di direktori utama.
4.  Buka `index.html` di browser modern pilihan Anda.
5.  Akses melalui `http://localhost/juara_vibe_coding/` (sesuai path server Anda).

---

## 📖 Cara Penggunaan
1.  **Pilih Tab**: Gunakan tab **Networking** untuk hitung IP atau **IoT Engine** untuk buat alat.
2.  **Input Data**: Masukkan parameter yang diminta (seperti IP Address atau Jenis Sensor).
3.  **Proses**: Klik tombol utama (Process/Generate) untuk melihat hasil instan.
4.  **Tanya AI**: Jika bingung, gunakan jendela chat **Lab Mate** di sebelah kanan. Anda bisa mengetik atau mengirim foto alat.
5.  **Simpan**: Klik **Download Lab Report** di bagian bawah untuk menyimpan hasil belajar Anda.
